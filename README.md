## Purpose

A community-maintained, open-access catalogue of all publicly documented datasets available for **Alzheimer's disease research**. Covers neuroimaging, genetics, proteomics, exposomics, transcriptomics, and clinical data.

## Structure

```
data/
  neuroimaging_genetics.json    ← Main structured dataset catalogue (JSON)
docs/
  contributing.md               ← How to add a dataset via Pull Request
schema.md                       ← Column definitions and validation rules
notebooks/
  explore_datasets.ipynb        ← (Coming) Interactive exploration notebook
```
